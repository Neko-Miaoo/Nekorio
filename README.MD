# Nekorio

Nekorio 是一个 iPhone 和 iPad 个人工具箱，目前提供自律打卡。最低系统要求为 iOS 18.2 或 iPadOS 18.2。

## 开始打卡

1. 在 Home 点「自律打卡」，或点底部「打卡」。
2. 点右上角的「＋」，从项目菜单创建或选择主项目。主项目可设置分组、图标、目标天数和提醒，也可以添加子项目。
3. 填写日期、子项目的数值或次数，按需添加备注和照片，然后保存。

首页项目条显示进度。轻点项目可查看详情，左滑可展开删除按钮，删除前需要确认。详情包含子项目目标、日历、周期统计、趋势图、年度热力图和记录时间线。「不超过」目标按实际记录逐日核对，只有当天有记录且未超上限才计为达成。

## 个性化与备份

- 在 **Home → 设置 → 主题色** 中选择常见色，或打开自定义色盘用滑杆调色。默认主题色为淡粉色。
- 在 **Home → 设置 → 数据备份** 中导出 JSON 文件。导入备份会与本机数据合并，同一条数据保留较新的版本。备份包含打卡记录、照片和主题设置。
